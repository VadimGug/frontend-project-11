# RSS Агрегатор

[![Actions Status](https://github.com)](https://github.com)
[![hexlet-check](https://github.com/VadimGug/frontend-project-11/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/VadimGug/frontend-project-11/actions)

Удобный веб-сервис для чтения RSS-лент в реальном времени. Приложение позволяет добавлять ссылки на RSS-потоки, автоматически валидирует их, фоново обновляет контент и предоставляет удобный интерфейс для предпросмотра статей в модальном окне.

## 🛠️ Стек технологий

*   **Язык:** JavaScript 
*   **Архитектура:** Реактивное состояние на базе библиотеки **Valtio**
*   **Стилизация:** **Tailwind CSS v4** (адаптивная верстка, поддержка Grid/Flexbox)
*   **Сетевые запросы:** **Axios** (работа с прокси-сервером All Origins для обхода CORS)
*   **Валидация данных:** **Yup** (проверка валидности URL и уникальности фидов)
*   **Интернационализация (i18n):** **i18next** (полная локализация интерфейса и кодов ошибок)
*   **Сборщик:** **Vite**

## 🚀 Ключевые возможности

*   **Валидация на лету:** Мгновенная проверка введенных данных без перезагрузки страницы (обработка пустых строк, невалидных URL и дубликатов).
*   **Автономное обновление:** Функция фонового мониторинга опрашивает добавленные фиды каждые 5 секунд с помощью рекурсивного `setTimeout` для предотвращения наслоения запросов.
*   **Удобный UX:** Нативные модальные окна `<dialog>` для предпросмотра описания статей, динамическое визуальное разделение прочитанных (тонкий шрифт) и новых (жирный шрифт) постов.
*   **Кастомный парсинг:** Чистая функция разбора XML-дерева через встроенный `DOMParser` с глубокой обработкой исключений (`parsererror`).

## 💻 Установка и запуск

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com
cd frontend-project-11
```

### Шаг 2: Установка зависимостей
```bash
npm install
```

### Шаг 3: Запуск сервера разработки
```bash
npm run dev
```
После этого откройте ссылку [Ссылка на сайт](https://frontend-project-11-navy-seven.vercel.app/) в вашем браузере.
